# Tema 2 POO - Situatii Note Studenti

## Descriere

Programul permite gestionarea notelor studentilor si generarea situatiilor scolare.

## Ierarhie de clase

- `Persoana` - clasa de baza 
  - `Student` - are note, calculeaza media, verifica promovabilitatea
  - `Profesor` - are materie si grupe predate
  - `Parinte` - are ocupatie si copii inscrisi la FMI
  - `Director` - are departament, poate aproba burse (adaugat in commit separat)
